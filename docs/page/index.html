hibiki

hibiki — аниме-клиент для поиска тайтлов, ведения личной библиотеки и просмотра серий с сохранением прогресса. Подключаемые источники, встроенный плеер и загрузки для просмотра офлайн.

Вопросы и ответы

Откуда берётся контент?

hibiki ничего не хранит и не раздаёт сам. Тайтлы и серии приходят из источников — расширений, которые устанавливаются из внешних репозиториев. Приложение только показывает то, что отдаёт источник.

Как добавить источники?

Откройте Источники → Репозитории → Добавить репозиторий и вставьте адрес его индекса. После этого источники из репозитория появятся в списке — установите нужные, и их каталог станет доступен в приложении.

Windows пишет «Система Windows защитила ваш компьютер»

Так SmartScreen реагирует на программы без платной цифровой подписи. Нажмите Подробнее → Выполнить в любом случае. Исходный код открыт, а установщик собирается из него на GitHub.

Android не даёт установить APK

Разрешите установку из этого источника: Android сам предложит это при открытии файла (в браузере или файловом менеджере). Дальше обновления приходят прямо в приложении.

Как перенести библиотеку на другое устройство?

В Настройки → Синхронизация одно устройство показывает код, а другое находит его в сети и вводит этот код. После этого библиотека, прогресс, оценки и достижения синхронизируются сами, пока устройства в одной сети. Работает между компьютером и телефоном, двумя компьютерами или двумя телефонами. Через интернет ничего не передаётся.

Это бесплатно? Есть реклама?

Бесплатно и без рекламы. Исходный код открыт под лицензией GPL-3.0.

Отказ от ответственности. hibiki не предоставляет, не хранит и не распространяет контент. Источники подключаются из внешних репозиториев, ответственность за соблюдение местного законодательства лежит на пользователе.
